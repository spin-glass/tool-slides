# 1. はじめに

本書では、工場の設備異常音検知システムの運用と移行について述べる。

製造業を取り巻く環境は大きく変化しており、設備保全の高度化はあらゆる企業にとって喫緊の課題となっている。

本システムの導入は、当社の保全業務を大きく変革する可能性を秘めていると考えられる。

# 2. 背景と対象

対象は、第2工場のプレス機12台である。第1工場の設備と、組立ラインの搬送機は対象外とする。

現在は、保全課の担当者が週1回、全台を巡回して耳で異常音を確かめている。巡回は1台あたり約15分（目安）で、異常の見逃しは月3件（2026年8月の実績）であった。

# 3. 検知の方式

各プレス機にマイクを付け、稼働中の音から異常スコア（0〜1）を1分ごとに計算する。

異常スコアが0.7以上になったとき、または注意域（0.5以上0.7未満）が同じ機械で3回連続したときに、保全課へ通知する。

AIによる検知は万能ではないため、その限界を十分に理解したうえで活用することが肝要である。

# 4. 運用

## 4.1 日常の運用

通知を受けた保全課は、必ず30分以内に現地で音を確かめ、結果を記録する。

保全課の現地確認は1回あたり20分を想定している（未実測）。

製造課は、通知があった機械の稼働を止めるかどうかを決める。

日々の運用においては、関係部署が緊密に連携し、迅速な対応に努めることが求められる。

## 4.2 モデルの更新

モデルは定期的に再学習する。

誤った通知が続いた場合は、適宜しきい値を調整する。

## 4.3 監視

通知のうち、現地で異常が無かったものの割合（誤通知率）が月次で50%を超えた場合は、生産技術課に報告する。

通知を受けた保全課は、必ず30分以内に現地で音を確かめ、結果を記録する。

# 5. 判定の基準

異常スコアが0.65以上の場合に限り、保全課へ通知する。

# 6. 合格条件

試行期間に、異常の見逃しが0件、かつ誤通知率が30%以下であれば、第2工場の全台に展開する。

合格条件は、運用状況を見ながら必要に応じて見直すものとする。

# 7. 移行

試行はプレス機3台で2か月行う（想定）。

試行の後、第1工場への展開を検討する。

移行は段階的かつ慎重に進めることが望ましい。

# 8. 体制

| 担当 | 役割 |
| :--- | :--- |
| 保全課 | 通知を受けた現地確認と記録、試行の評価 |
| 製造課 | 通知があった機械の稼働を止めるかの判断 |
| 生産技術課 | 誤通知率の報告を受けた対応、マイクの設置 |

保全課の現地確認は1回あたり20分を想定している（未実測）。

# 9. 情報の取り扱い

録音には作業者の会話が入ることがあるため、音声は30日で消去し、異常スコアだけを1年保存する。

情報セキュリティについては、関連規程に従い適切に管理する。

# 10. 未決事項

夜間（22時〜6時）の通知の宛先は未定である（保全課長が決める）。

詳細な仕様は §13 を参照。

# 11. おわりに

本システムにより、設備の突発停止が減少し、生産性が向上することが期待される。

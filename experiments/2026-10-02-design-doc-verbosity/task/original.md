# 1. はじめに

本書では、社内規程問い合わせボットの運用と移行について説明する。

近年、生成AIの活用はあらゆる業界で急速に広がっており、当社においても業務の効率化と従業員体験の向上が強く求められている。

AIシステムは導入して終わりではなく、継続的に改善していくことが重要である。

本書は、関係者が共通の理解を持ち、円滑に運用を進めるための指針となることを目指す。

# 2. 対象と範囲

対象は、人事・総務の社内規程（就業規則・経費規程・旅費規程）について、従業員から寄せられる質問である。経理の個別の精算処理（特定の申請の承認状況など）に関する質問は対象外とする。

現在は、総務課の担当者2名が社内チャットで質問に手で回答しており、問い合わせは月約600件（2026年7月の実績）である。

様々な観点から検討した結果、ボットによる自動回答を導入することが望ましいと考えられる。

# 3. 変更後の方式

ボットは、規程の文書から回答案を作り、回答の根拠となる条文を必ず表示する。根拠となる条文を示せない質問は、総務課の担当者へ回す（以下「担当者へ」）。

根拠条文の類似度が0.75以上であれば自動で回答し、0.75未満であれば担当者へ回す。

回答の根拠となる条文を表示することは、利用者の信頼を得るうえで非常に重要である。

ユーザー体験の向上は常に意識する必要がある。

# 4. 運用

## 4.1 日常の運用

日常の運用は、極力人手を介さず自動化することを目指す。

総務課は、担当者へ回された質問に回答し、ボットの回答のうち毎日20件を抜き取って確認する。総務課の確認作業は1日30分を想定している（未実測）。

情報システム課は、ボットの稼働状況を監視し、通知に対応する。外部ベンダーは、回答モデルと検索の設定を調整する。

## 4.2 監視

「担当者へ」の割合が週次で40%を超えた場合は、情報システム課に通知する。

障害が発生した場合は、迅速かつ適切に対応する。

## 4.3 規程の更新

規程を改定した場合は、改定日から3営業日以内に検索の索引を作り直す。

規程の改定は頻繁に行われるため、常に最新の状態を保つことが求められる。

# 5. 判定の基準

根拠条文の類似度が0.8以上の場合に限り、自動で回答する。

ボットは、規程の文書から回答案を作り、回答の根拠となる条文を必ず表示する。

# 6. 合格条件

評価用の質問300件で、誤回答率が2%以下、かつ担当者へ回す割合が30%以下であれば、全社に公開する。

現行（人手）の誤回答率は約3%である（目安。2026年10月に再集計する）。

合格条件については、状況に応じて柔軟に見直すことも検討する。

# 7. 移行

試行は総務課の中だけで1か月行い、その後全社に公開する。期間は想定であり、確約ではない。

移行にあたっては、関係者が密に連携し、円滑なコミュニケーションを図ることが重要である。

# 8. 体制

| 担当 | 役割 |
| :--- | :--- |
| 総務課 | 担当者へ回された質問への回答、ボットの回答の抜き取り確認、規程の更新 |
| 情報システム課 | 稼働の監視、通知への対応 |
| 外部ベンダー | 回答モデルと検索の調整 |

総務課の確認作業は1日30分を想定している（未実測）。

# 9. 情報の取り扱い

セキュリティには万全を期す必要がある。

質問文に含まれる社員番号は、ログに保存する前に伏せる。ログの保存期間は1年とする。

# 10. 未決事項

担当者へ回した質問の回答期限は未定である（総務課長が決める）。

要件の詳細は §12 を参照。

# 11. おわりに

本ボットの導入により、従業員の利便性が大きく向上することが期待される。

今後も、利用者の声に耳を傾けながら、さらなる改善を目指していく。

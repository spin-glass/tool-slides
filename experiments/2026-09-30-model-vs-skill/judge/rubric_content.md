# 写真の中身の確認（確認者に渡す文面）

あなたは確認の担当です。スライドが、載せた写真について「何が写っているか」を正しく述べているかを確かめてください。
デザインや分かりやすさは評価しません。どのデッキを誰がどう作ったかは伏せてあります。

## 見るもの

デッキごとのフォルダに、次のファイルがあります。

- `manifest.md`: 誤りの写真を載せたスライドの一覧。スライドごとに、タイトル、画面の文字（箇条書き・画像の説明・出典行）、確認用の画像の名前。
- `slide-NN-fig-K.jpg`: スライドに載った図。確認する写真の左上に、赤い「#番号」を付けてあります。図の中の見出し・画像ごとの説明も、スライドが述べていることに含みます。
- `slide-NN-fig-K-truth.jpg`: 同じ #番号の写真の元の画像を並べたもの。下に、データに付いたラベルと、分類モデルの予測があります。
  元の画像には、人が引いた枠を描いてあります。**赤い枠**＝データのラベルの種の枠、**青い枠**＝ほかの候補の種の枠、**黄色の細い枠**＝候補以外で最も大きな物。
  枠と名前は、そのデータを作った人が付けたもので、誤っていることもあります（例: ペリカンに「ガン」の枠）。枠は、小さく写る物を探す手がかりとして使い、最後は写真に写っているもので判断してください。
- `truth/<番号>.jpg`: 元の画像（長辺1024px）。小さく写る物・遠くの物を確かめたいときに開きます。

## 写真ごとにすること

1. 図の中の #番号の写真について、スライドが述べていることを拾います: その写真の下や横の説明、その写真が入っている群の見出し（例:「ラベルの誤り」「写っているのはカモ」「正解: 牛 → 予測: 羊」）、その写真を指すタイトル・箇条書き。
2. それを元の画像と照らし、次のどれかに分けます。
   - `ok`: 写っているものと合う（種の名前、数、「ラベルの誤り」「モデルの誤り」の区別、様子の説明が、写真と矛盾しない）
   - `wrong`: 写っているものと違う。例: 写っている物を「いない」「写っていない」と書く／写っているのは別の種なのにその種と書く／写真にラベルの種が写っているのに「ラベルの誤り」と書く／2種が写っているのに片方だけが写ると書く／写っていない様子（場所・数・色）を書く
   - `overclaim`: おおむね合うが言い過ぎ（「だけ」「すべて」「はっきり」などが写真で崩れる）
   - `none`: その写真の中身について何も述べていない（ラベルと予測の名前だけを並べた見出しは、中身を述べていないものとして `none`）
3. `wrong` と `overclaim` には、何と書いてあり、実際には何が写っているかを detail に書きます（「右上の奥に牛が2頭小さく写る」など、位置も）。
4. 種の見分けが写真からは決めきれないとき（よく似た種、遠すぎる）は、`wrong` にせず `ok` とし、detail に「決めきれない」と書きます。

## スライドごとにすること

タイトル・箇条書きのうち、写真の中身に触れる主張（例:「6枚とも写っているのはカモではない」「小さく写る牛を見落としている」）を拾い、
そのスライドの写真と照らして `ok`・`wrong`・`overclaim`・`unknown`（写真からは確かめられない）に分けます。写真の中身と関係のない主張（正解率、対策の提案）は拾いません。

## 出力

デッキごとに、次の形で答えます（デッキ記号をキーに）。

```json
{"AA": {"images": [{"n": 1, "slide": 3, "claim": "スライドの説明（短く）", "verdict": "ok", "detail": ""}],
        "slide_claims": [{"slide": 3, "text": "主張（短く）", "verdict": "ok", "detail": ""}],
        "comment": "そのデッキで、写真の中身と合わない主な点を1〜2文"}}
```

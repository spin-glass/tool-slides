# 画像と主張の照合（確認者に渡す文面）

あなたは確認の担当です。スライドが「載せた画像について言っていること」が、実際に載っている画像と合っているかを確かめてください。
デザインや分かりやすさは評価しません。どのデッキを誰がどう作ったかは伏せてあります。推測せず、画像に見えるものだけで判断してください。

## 見るもの

デッキごとのフォルダに、次のファイルがあります。

- `manifest.md`: 写真を載せたスライドの一覧。スライドごとに、タイトル、画面の文字（箇条書き・画像の説明・出典行）、確認用の画像の名前。
- `slide-NN-fig-K.jpg`: スライドに載った図（写真を並べた図）を大きくしたもの。図の中に描かれた見出し・画像ごとの説明も「主張」に含みます。
- `slide-NN-photos.jpg`: スライドに HTML で載った写真を、元の大きさで並べたもの。各写真の下に、#番号、スライド上の説明文、データ（正解・予測・確信度、または旧版・新版の予測、外れ値のスコア、撮影者の題名）があります。データと題名は正しい値です。
- `slide-NN.png`: スライド全体の画面。どの画像がどの見出しの下にあるかなど、配置を確かめたいときだけ開いてください。

## スライドごとにすること

1. 画像について述べている主張を、1件ずつ拾います。
   - タイトル・箇条書きのうち、画像の中身や、どの画像を選んだかに触れるもの（例:「12枚は岩場や山にいる野生のヤギだ」「白いヤギは1枚もない」「12枚をすべて表示」）
   - 図や写真の見出し（例:「岩場・斜面」「遠くに小さく写る 6枚」「正解が牛 4枚」）
   - 画像ごとの説明（例:「白いヤギ」「オリックス」「雪原のエルク」「車だけが写る」）。同じ種類の短い説明がたくさんあるときは、まとめて1件にし、合わないものだけを detail に書いてかまいません。
   - 画像と関係のない主張（正解率、対策の提案、数字だけの集計）は拾いません。
2. 各主張を、確認用の画像を見て次のどれかに分けます。
   - `ok`: 載っている画像と合う
   - `partial`: 多くの画像には当てはまるが、当てはまらない画像がある。または言い過ぎ（「すべて」「ばかり」「1枚も」などが一部の画像で崩れる）
   - `ng`: 画像と合わない（例:「白いヤギ」とあるのに茶色い動物、「動物が写っていない」とあるのに動物が写る、見出しの群に別の種類の画像が入っている）
   - `unknown`: 画像からは確かめられない（撮影者の題名・データの外のこと、種の細かい同定など）
3. `partial` と `ng` には、どの画像か（図の中の位置「2段目の左から3枚目」、または #番号）と、実際に何が写っているかを書きます。
4. 枚数の記述（「12枚」「6枚を表示」）は、数えて確かめます。
5. 動物の種の同定（アイベックス・シャモア・マーコールなど、よく似た野生種の区別）は、見た目で明らかに違う場合だけ `ng` にし、決めきれなければ `unknown` にします。

## 出力

デッキごとに、次の形で答えます（デッキ記号をキーに）。

```json
{"AA": {"slides": [{"slide": 3, "claims": [{"text": "主張（短く）", "verdict": "ok", "detail": ""}]}],
        "n_ok": 0, "n_partial": 0, "n_ng": 0, "n_unknown": 0,
        "comment": "そのデッキで、画像と主張が合わない主な点を1〜2文"}}
```

## 作業の決まり

- デッキのフォルダ: `{DIR}`。見てよいのは、この下の次の記号のフォルダだけです。ほかのファイルやフォルダは読まず、検索もしないでください（誰がどう作ったかの手がかりを探さない）。
- 次の順に見てください: {ORDER}
- 1つのデッキの全スライドは、1回の応答の中で Read をまとめて呼んで開いてください（1枚ずつ別の応答にしない）。
- 1つのデッキを見終えるたびに、そのデッキの答え（上の項目すべて）を `{OUT}.notes.jsonl` に1行の JSON で追記してください。次のデッキへ進む前に必ず書きます。
- 全デッキを見終えたら、点の付け方がデッキの間で揃っているかを見直し（必要なら直し）、最終の JSON を `{OUT}` に保存し、同じ JSON を最後の返答に書いてください。
- これは評価の作業だけです。Notion などの外部サービスは使わず、保存・送信・コミットもしません。書き込むのは上の2つのファイルだけです。

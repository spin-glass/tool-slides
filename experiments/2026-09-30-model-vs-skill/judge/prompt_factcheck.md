## 作業の決まり

- 参照図: `{REF1}`（{REF1_NOTE}）と `{REF2}`（{REF2_NOTE}）。最初に2枚とも Read で開き、画像を1枚ずつよく見てください。
- デッキのフォルダ: `{DIR}`。見てよいのは、参照図と、この下の次の記号のフォルダだけです。ほかのファイルやフォルダは読まず、検索もしないでください（誰がどう作ったかの手がかりを探さない）。
- 次の順に見てください: {ORDER}
- 1つのデッキの全スライドは、1回の応答の中で Read をまとめて呼んで開いてください（1枚ずつ別の応答にしない）。
- 判断の材料は参照図の画像だけです。デッキのスライドに載っている画像や説明を、正しさの根拠にしないでください。迷ったら参照図を開き直して確かめてください。
- メモは追記だけにしてください（ファイル全体を書き直さない。前の行は消さない）。1行は {{"記号": 答え}} の形にします。
- 1つのデッキを見終えるたびに、そのデッキの答えを `{OUT}.notes.jsonl` に1行の JSON で追記してください。次のデッキへ進む前に必ず書きます。
- 最後の見直しでは画像を開き直さず、メモを読み返して基準を揃えてください。直したデッキがあれば、その答え全体を1行追記します。
- 全デッキを見終えたら、判断の基準がデッキの間で揃っているかを見直し（必要なら直し）、最終の JSON を `{OUT}` に保存し、同じ JSON を最後の返答に書いてください。
- これは確認の作業だけです。Notion などの外部サービスは使わず、保存・送信・コミットもしません。書き込むのは上の2つのファイルだけです。

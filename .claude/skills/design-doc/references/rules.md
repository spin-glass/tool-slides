# 数値ルール（lint・check_doc が機械的に検査する）

`SKILL.md` から移した正本（2026-10-07）。slides の `references/rules.md` に足す分。block と warning の名前は検査の出力と同じ。

| 対象 | 目標 | block |
|---|---|---|
| 確認点 `::: {.check}`（kind: confirm の本編） | 1枚に1つ、全角40字以内、1行 | 0個・2個以上・40字超 |
| 確認型のタイトル | 決めたことを「〜します」で言い切る。2行まで | 全角56字超（40px で1行約28字） |
| まだ決めていない値 `[要確認]{.tbd}` | 1枚目の `::: {.undecided}`（まだ決めていない点の一覧）に対応 | 一覧が無いのに `.tbd` がある |
| 主張ID `<!-- claims: C1,C2 -->` | `claims.csv` の id | 無い id／未決の主張を載せた枚が未決と分かる形でない |
| `claims.csv` | 列9つ・状態7つ（`references/claims.md`） | 列・状態・target の誤り、事実・決定に evidence が無い |
| 設計書の章参照（§3.4・3.4節・第3章） | 本文にある章 | 無い章（他の文書は「基本設計 §5.1」「原文 §2」と文書名をすぐ前に付ける） |
| Mermaid | 1行目が図の種類（flowchart / gantt / …） | 種類でない・描画エラー |
| 設計書の placeholder | 0（`[要確認]` は未決の印として可） | TODO・TBD・XXX・〇〇 |
| 中身の無い段落（削除候補） | 0 | 数字・主張ID・§・`コード`・「固有の語」・`[要確認]` のどれも無く、一般論・前置き・ヘッジだけの段落か箇条書き（「〜を〜する」の作業の文があれば block にせず warning。語だけ外す） |
| 繰り返し | 0 | 文書内で同じ文（全角20字以上）が2回、同じフォルダの別の設計書と同じ文（全角30字以上） |
| 読む字数（文章＋表のセル。図のラベルは上限の比較に数えない） | 上限は、原文と「原文から削除候補と繰り返しを除いた中身の1.5倍」の小さい方 | —（超えると warning） |
| 同じ主張・同じ数値を書く場所 | 正本の章と §1 の要点の2か所まで | —（同じ主張ID・同じ「数値＋単位」が3回以上で warning） |
| §1 | 4つの要点（次へ進む条件は値で）と、まだ決めていない点だけ。1.1 を含めて読む字数の3割まで | —（3割超で warning） |
| 本文の主張ID・`[要確認]` | 主張IDは本文に見せない（コメントに書く）。`[要確認]` は §1.1（7行を超える分は付録）で1回 | —（本文に見える主張ID・§1 と付録の外の `[要確認]` で warning） |
| 前置き（本文の中身が始まるまでの、冒頭の表・文書の説明の章・引く表の章） | 1000字まで。冒頭に置くのは「扱うこと／読む人／原文／状態」の表と §1 だけ | —（超えると warning） |
| §1 の中身 | 何を変えるか・次へ進む条件（値か「原文に無い」）・まだ決めていない点・決めたこと。題ではなく中身で見る | —（無い項目は助言（info）で知らせる。必須にしない。長い文書だけ） |
| 引く表の章（表が7割以上で、表の行が合計10行以上か要件IDが5回以上） | 付録に置く | —（読む路の途中にあると warning） |
| 章の型（文・表・図・箇条書きの並び。先頭3要素で比べる） | 同じ型で始まる章を3章以上続けない。章の問いで型を選ぶ | —（warning。長い文書だけ） |
| 読み通す章の合計 | 6000字まで（1回で読める量）。冒頭の表に読む人ごとの章があれば、読む人ごとの経路の最長で測る（無ければ引く表の章と付録を除く全部） | —（超えると warning） |
| 読む人 | 2者以上なら、冒頭の表でそれぞれが読む章を § で添える。その章から読まない章を参照しない（§1 と提案の章は数えない） | —（warning。`reader-entry`・`reader-path-dep`） |
| 表の隣の段落 | 表にあることを書かない。表の直前・直後の短い段落（全角80字以下）は、表に無いこと（決定・例外・次にすること）だけ | —（見出しの語の7割以上・段落の語の7割以上が表にある、表の行数と同じ数を言う、で warning。`table-dup`） |
| 未決の一覧 | §1.1 に件数と判断に関わる行（7行まで）。残りは付録「未決の一覧」 | —（§1 の表が8行以上、未決の章が末尾にあって本文から3回以上参照される、で warning） |
| 本文の章参照・識別子 | 別の章を参照する段落は本文の半分まで（§1・同じ章・他の文書への参照は除く）。識別子（要件ID FR-001 の形、「決定#12」「確認が要る事項#3」「#7」）は本文に4回まで（付録の対応表は除く） | —（warning。`ref-share`・`opaque-id`） |
| 冒頭の表 | 「この文書が扱うこと／読む人／関連文書／版」の4行（関連文書が無ければ「無い」）。進行管理（「執筆完了」）は書かない | —（行が無いと warning。長い文書だけ。`doc-header`） |
| 括弧の中 | 言い訳を書かない（「〜ため」「〜できない」「〜ではない」で終わる括弧） | —（warning。`excuse-paren`） |
| 補足（`#### 補足` の箇条書き） | 決定に無いこと（理由・例外・測り方）だけ。1文目で同じ節の太字の文（決定）を言い直さない | —（warning。`restated-decision`） |
| 表の行数 | 本文に「N点」「N件」「Nつ」と数え直して書かない（表が変わると古くなる）。図・表の題は可 | —（同じ章の表の行数と同じ数で warning。`recounted-number`） |
| プロジェクトの NG 語 | 文書ごとの独自の語を作らない。プロジェクトの `plans/doc_ng_phrases.md`（設計書のフォルダから上へ探す。`DESIGN_DOC_NG` で別のファイル）の語を使わない | —（warning。`coined-term`） |
| 図のラベル | 短い名詞。章参照（§）を書かない。半角の文字を含む行を一番長くしない | —（warning） |
| 図の形 | 分岐・合流・戻りがあるときだけ図。行と列の対応（いつ・何を・どうする）は表、分岐の無い一本道は番号つきの手順 | —（互いにつながらない流れが3つ以上、4個以上の一本道で warning） |
| 図のラベルの長さ | 箱は1行全角12字、辺は8字まで。意味の切れ目に `<br>`。1つの箱に「。」で2文を詰めない | —（warning） |
| 図の色と題 | 先頭に `--mermaid-init` の今の1行、末尾に `--mermaid-classes` の5行（色はこの5つだけ）。図の直後に「図N 題」の1行 | —（init が古い版・ほかの classDef／style・題が無い、で warning） |

warning（止めないが直す）: 章（`##`）の見出しの直後に図（Mermaid・表・画像）が無い（読む字数1500字以上の文書だけ）、章番号（`## 3.` / `### 3.1`）のない見出し、確認型の本編の枚に `claims` が無い、1段落が全角200字超・1章の文章が1000字超、一般論・前置き・ヘッジが1段落に2つ以上・文章1000字あたり3つ超、バズワード、表のセルが一般論だけ・表どうしで同じセル、同じ主張IDが3か所以上（再掲）、読む字数が上限（原文は `design/_source/<同じ名前>.md`）を超えた、ひし形のラベルの1行が8字超、半角の文字を含む行が一番長い図のラベル（描くと右端が欠ける）、図のラベルの章参照（この3つは erDiagram・classDiagram では見ない。`{ … }` は属性の並び）、図の形（つながらない流れが3つ以上→表、一本道→手順）、箱のラベルの1行が12字超・辺が8字超・「。」で2文、共通の5つ以外の色、図の下の「図N 題」が無い、古い init、全行が同じ値か空欄の表の列、本文に見える主張ID、§1 と付録の外の `[要確認]`、設計書に載せるはずの主張（`claims.csv` の target が doc / both）が本文に出てこない（削りすぎ）、一般論の語を含む作業の文（削らず語だけ外す）、未決・提案に決める担当が無い（claims.py）。
構造（`scripts/structure.py`。冗長さを0にしても構造が同じなら読む気は戻らない）: 前置きが1000字超、§1 が無いか文書の説明になっている、§1 の表が8行以上、引く表の章が読む路の途中、同じ型で始まる章が3章以上続く、読み通す章の合計が6000字超、読む人が2者以上なのに読む章が無い、読む人ごとの章が読まない章を参照する、未決の一覧が末尾にあって本文から参照される、別の章を参照する段落が本文の半分超、要件IDが本文に5回以上、表の隣の段落が表にあることを書いている、§1 に付録への入口が無いまま本文から付録へ5回以上飛ばす。§1 の4つの要点のどれかが無いことは助言（info）。
辞書は `references/ng_doc.md`（一般論・前置き）と slides の `references/ng_words.md`（ヘッジ・バズワード）。閾値は `scripts/verbosity.py` の `LIMITS`（初期値）。

このスキルの frontmatter の `hooks` は Claude Code だけが読む（プロジェクトの `.claude/skills/` → `~/.claude/skills/` の順に探し、どちらも無ければ何もしない）。

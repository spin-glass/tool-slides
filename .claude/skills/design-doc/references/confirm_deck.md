# 確認型スライド — 決めたことを伝えて齟齬を確かめる

## 型

意思決定者に「決めてもらう」構成ではなく、こちらで決めた内容を1枚ずつ伝え、認識に齟齬がないかを確かめる構成。
本人の決定（2026-10-01）: どうするかはこちらで決め、意思決定者には決めたことを伝えて齟齬がないことを確認してもらう。

**1枚＝決めたこと1つ＋確認点1つ。** 文字の型（タイトル＋箇条書き3つ＋出典）に、下端の「確認点」の帯を足した型。

| 枚 | 内容 | 必ず置くもの |
|---|---|---|
| 1枚目 本日の確認 | 「〜について決めたN点をお伝えします。認識と違う点があれば指摘してください」。左に決めたN点（2枚目以降の見出しを短くした文）、右に「まだ決めていない点」 | `::: {.undecided}`、確認点 |
| 2〜N枚目 決めたこと | タイトル＝決めたこと1つを「〜します」で言い切る。本文はその対照表・条件・図（根拠3点まで） | 確認点、`<!-- claims: -->` |
| 最後 体制と進め方 | 担当・工数・時期。工程表と担当の札。取れていない数字は `[要確認]{.tbd}` | 確認点 |
| 付録 | 設計書で片付ける整理（規則の統一、本番の設定の番号）、主張の表の一覧（claims.csv を読むコードセル） | 「付録」の印（自動） |

本編に出さないもの: 担当者間で片付く設計の整理（判定規則の統一、本番の設定の単位、組織名の対応）、技術製品名の候補、指標の公式、全ログ項目、障害対応手順。判断に影響する未確定事項は該当の枚に短く残し、各枚を注意書きで埋めない。

## 書き方（理由つき）

<style_guide>

- **タイトルは決めたことを丁寧体で言い切る**（「〜に変えます」「〜なら切り替えます。満たさなければ現行を続けます」）。聴衆に向けた宣言なので「〜だ」より「〜します」。条件と、満たさないときの扱いまで1文に入れてよい。2行（全角56字）まで。lint は `kind: confirm` のとき56字で止める。
- **確認点は「何を確かめてほしいか」だけを1行で（全角40字以内）。**「現行の説明と対象範囲に違いがないか」「『確認作業がなくなる』という期待とずれていないか」「条件と、満たさない場合の扱い」。本文の要約を書かない。帯は24px、左に青の縦線4px、下端に1本だけ。
- **まだ決めていない値は `[要確認]{.tbd}` で灰の点線の枠に残す。** 数字が取れるまで埋めない。推測で埋めると、意思決定者は決まった数字として受け取る。1枚目の「まだ決めていない点」に同じ項目を載せる（載せないと lint が止める: tbd-without-list）。
- **決めたことの出所を `<!-- claims: C1,C2 -->` に書く。** 未決の主張（status 未決）を載せた枚は、未決と分かる形にする（lint: claims-undecided-hidden）。参考値・想定を「実績」「確約」の言葉にしない。
- **1枚目の決めたN点は、2枚目以降の見出しと同じ内容を短くした文にする。** 1枚目だけで全体が分かり、以降は1点ずつの確認になる。
- **図は向きと関係だけでも描き、実測値が無ければそう書く。**「棒の長さは関係の向きを示す。実測値が入るまで比率は仮」。見かけの数字を作らない。
- **最後の枚で各段階の戻し方に触れる。**「各段階で4枚目の条件を満たさなければ手入力へ戻す」のように、前の枚の条件を参照する。
- **設計書の図（Mermaid）はそのまま付録に流用できる。** `{mermaid}` のセルに `%%{init: {"themeVariables": {"fontSize": "24px"}}}%%` を付けて文字を20px以上にする。

</style_guide>

## マークアップ（`theme/custom.scss` の確認型の部品）

| 書き方 | 見た目 | 用途 |
|---|---|---|
| `::: {.check}` 本文 `:::` | 下端の帯。「確認点　」が青の太字で先頭に付く | 各枚に1つ |
| `::: {.undecided}` 段落1つ＝1項目 `:::` | 「まだ決めていない点」の見出しと点線の枠 | 1枚目の右の列 |
| `[要確認]{.tbd}` / `[要確認]{.tbd .big}` | ［要確認］を灰の点線の枠で。`.big` は56px | 取れていない数字の位置 |
| `:::: {.columns .pair}` ＋ `.column`×3（現行／`[→]{.arrow}`／変更後） | 右の列に青の縦線。`### 見出し` は20pxの灰（右の列は青） | 現行→変更後 |
| `::: {.outcome .accent}` 条件 ／ 結果 `:::`、`::: {.outcome}` | 左に縦線。1行目18px、2行目太字 | 満たす／満たさないときの扱い |

## ゴースト段階

タイトルと確認点だけで骨子を見せる。確認点は `<!-- check: … -->` のコメントで書き、`lint_slides.py --titles` の連読に「確認点:」として出る。承認後に `::: {.check}` にする。雛形は `decks/_template_confirm/index.qmd`。

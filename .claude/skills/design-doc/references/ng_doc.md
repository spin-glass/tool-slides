# 設計書の冗長さの辞書

`scripts/verbosity.py`（`check_doc.py` から使う）がこのファイルの ```` ```ng:<class> ```` フェンスを読み、1行1正規表現として使う。
slides の `references/ng_words.md` の hedge（ヘッジ・言い訳）と buzzword（中身のない抽象語）も、設計書の文章に同じように当てる。
「」の中は語の引用なので数えない。語を足すときはフェンス内に1行追加するだけでよい。

| クラス | 何を見つけるか | 置き換え方 |
|---|---|---|
| generic | 一般論・心構え（誰が・いつ・何を・どの値で、が無い） | 担当・時期・数値・条件に置き換える。置き換えられなければ段落ごと削る |
| meta | 文書についての前置き（「本書では〜を説明する」） | 削る。見出しと冒頭の表が同じ役目をする |

数字・主張ID（C1）・章参照（§）・`コード`・「固有の語」・`[要確認]` のどれも無い段落にこれらの語があれば、`check_doc.py` は削除候補として止める（block）。
中身のある段落でも、2つ以上あれば warning。

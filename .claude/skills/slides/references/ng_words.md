# NG辞書（3クラス）

`scripts/lint_slides.py` がこのファイルの ```` ```ng:<class> ```` フェンスを読み、1行1正規表現（大文字小文字無視）として使う。
`#` で始まる行はコメント。語を足すときはフェンス内に1行追加するだけでよい。

| クラス | lint の扱い | 狙い |
|---|---|---|
| buzzword | warning（1件ごと） | 中身のない抽象語。具体的な対象・数字に置き換えさせる |
| hedge | warning（1枚2個以上／本編で0.3個/枚超） | 不確実な箇所の水増し（verbosity compensation）と、指示文・前置きの本文への流用を見つける |
| placeholder | block | 未確定のまま出力されるのを止める |

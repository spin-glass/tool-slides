# スライドの型 — Claude Design「スライド型見本」の部品

本文を書く前に、各枚の証拠の形から型を1つ選ぶ。型の見た目は `theme/custom.scss`（CSS の部品）と `scripts/figs.py`（図）に実装済みで、どのデッキでも同じ見た目になる。
型の出所: Claude Design「スライド型見本」（3デッキ28枚の棚卸し 2026-09-30、確認型 4a 2026-10-01）。

骨子（フェーズ2）で各枚に `<!-- type: pair -->` のように型を書き、本文ではその型の書き方を使う。
lint は、知らない型を止め（block）、型に必要な書き方が本文に無い枚・型を書いていない本編の枚を知らせる（warning）。

## 型の選び方

| 証拠の形 | 型 | 書き方（lint が探すもの） | 見た目 |
|---|---|---|---|
| 事実・数字が3点まで | `text` | 箇条書き3つ（何もなくてよい） | タイトル＋箇条書き＋出典 |
| 前と後・現行と変更後・A案とB案 | `pair` | `:::: {.columns .pair}` | 左＝前（灰の見出し）、`[→]{.arrow}`、右＝後（青の縦線と見出し） |
| 条件と、満たす／満たさないときの扱い | `outcome` | `::: {.outcome}`（満たすほうに `.accent`） | 左に縦線、1行目＝条件18px、2行目＝結果を太字 |
| 結論を1〜2個の数字で言う | `number` | `[値]{.big}`（未取得なら `[要確認]{.tbd .big}`） | 56px の太字。見出しは `[…]{.small .muted}` |
| 担当・体制 | `roles` | `:::: {.columns .roles}` | 上辺に青の線、1行目＝担当を太字 |
| 期間・段階 | `timeline` | `figs.timeline(...)` | 工程表。既定は青、注目させる段だけ橙 |
| 実測値の無い関係の向き | `direction` | `figs.direction(...)` | 「Aを上げるとBが減りCが増える」を棒の向きで。但し書き必須 |
| 数の比較・推移 | `chart` | `figs.bars(...)` か matplotlib のセル | 主張の系列だけ青、残りは灰 |
| 手順・分岐 | `flow` | `{mermaid}` のセル | PNG で描く。先頭に `check_doc.py --mermaid-init 24px` の1行 |
| 項目×属性の対照 | `table` | Markdown の表、または表を出すセル | 24px・横線1px |
| 具体例の写真 | `images` | `imgfig.*_figure(...)` か `![…](…)` | SKILL.md「具体例の画像を並べる」 |

迷ったら `text` にする。型を足すために証拠を作らない（図に見せる数字が無いなら `chart` にしない）。
1枚に型は1つ。`pair` の右に数字を置きたくなったら、主張が2つ入っていないかを先に疑う。
`number` と `chart`、`table` と `outcome` のように主従がはっきりした組み合わせは、主のほうを `type` に書く（見本の4枚目は `outcome`、3枚目は `direction`）。

## 書き方

### pair（前→後）

```markdown
:::: {.columns .pair}
::: {.column width="44%"}
### 現行

経理課が PDF を見て会計システムに手で入力

[打ち間違いは月次の照合まで見つからない]{.muted}
:::
::: {.column width="8%"}
[→]{.arrow}
:::
::: {.column width="44%"}
### 変更後

OCR で読み取り、自信がない項目だけ人が確かめる
:::
::::
```

- 左右の段落は同じ数・同じ順にそろえ、行ごとに対応させる（左の1行目と右の1行目が同じ観点）。
- 見出しは「現行／変更後」「前／後」「A案／B案」の2〜4字。段落は24px なので1段落は全角20字前後まで。

### outcome（条件→結果）

```markdown
:::: {.columns}
::: {.column width="62%"}
| | 条件 | 基準 |
|---|---|---|
| ① | 項目別の読み誤り | 手入力 以下 |
:::
::: {.column width="6%"}
[→]{.arrow}
:::
::: {.column width="30%"}
::: {.outcome .accent}
3つすべて満たす

切り替える
:::
::: {.outcome}
1つでも満たさない

手入力を続ける
:::
:::
::::
```

- 満たさないときの扱いを必ず置く。片側だけでは、読み手は「満たさなかったら？」を質問するしかない。

### number（大きな数字）

```markdown
[手入力の誤り率（現行）]{.small .muted}

[`{python} f"{err:.1%}"`]{.big}

**[「保留」の上限]{.small .accent-2}**

[要確認]{.tbd .big}%
```

- 数字はコードで計算して埋める。取れていない数字は `[要確認]{.tbd}` で残し、1枚目に `::: {.undecided}` の一覧を置く（lint: tbd-without-list）。
- 2つまで。3つ以上なら `table` か `chart` にする。

### roles（体制）

```markdown
:::: {.columns .roles}
::: {.column width="31%"}
経理課

「保留」の確認　月 [要確認]{.tbd} 時間
:::
::: {.column width="31%"}
情報システム課

会計システムとの連携・切替
:::
::::
```

- 1行目は担当の名前だけ。2行目以降はその担当がやることを1〜2行。`timeline` の下に置くと、いつ誰が何をするかが1枚で読める。

### timeline / direction / chart（図）

```python
#| fig-alt: "移行の4段階の工程表。1か月目に試験導入、2か月目に並行運用、3か月目に本番切替と定常運用。"
#| fig-width: 12.4
#| fig-height: 2.5
figs.timeline([("試験導入", 0.0, 0.9), ("並行運用", 1.1, 0.8, figs.ORANGE),
               ("本番切替", 2.0, 0.5), ("定常運用", 2.55, 0.45)], ["1か月目", "2か月目", "3か月目"])
```

```python
#| fig-alt: "閾値と読み誤り・「保留」の関係を向きだけ示した模式図。…棒の長さは実測値ではない。"
#| fig-width: 7.2
#| fig-height: 3.1
figs.direction([("閾値を上げる", [("読み誤り ↓", 0.6), ("「保留」↑", 0.7, figs.ORANGE)]),
                ("閾値を下げる", [("読み誤り ↑", 0.8), ("「保留」↓", 0.3, figs.ORANGE)])])
```

```python
#| fig-alt: "型ごとの件数。店内の写真が30件で最も多い。"
#| fig-width: 13.3
#| fig-height: 3.6
figs.bars(df["型"], df["件数"], highlight="店内", unit="件")
```

- 最初の図のセルの前に、`include: false` のセルで `import figs` と `figs.setup()` を1回書く（import の書き方は `figs.py` の先頭）。
- `direction` は実測値が無いときだけ使い、`[棒の長さは関係の向きを示す。実測値が入るまで比率は仮]{.small .muted}` を添える。実測値があれば `chart`。
- 色は青（主張）・橙（もう1つの群、注目させる段）・灰（強調しない）の3つまで。凡例を置かず、ラベルを棒の横に書く。

## 確認型だけの部品（design-doc スキル）

| 書き方 | 見た目 | 用途 |
|---|---|---|
| `::: {.check}` 本文 `:::` | 下端の帯。「確認点　」が青の太字で先頭に付く | 確認型の各枚に1つ |
| `::: {.undecided}` 段落1つ＝1項目 `:::` | 「まだ決めていない点」の見出しと点線の枠 | 1枚目の右の列（`.tbd` を使うデッキすべて） |

## 共通の部品

| 書き方 | 見た目 | 用途 |
|---|---|---|
| `[要確認]{.tbd}` | ［要確認］を灰の点線の枠で | 取れていない数字の位置 |
| `[注記]{.small .muted}` | 20pxの灰 | 図の但し書き |
| `[語]{.accent-2}` | 橙 | 2つ目の群の見出し |
| `[出典]{.source}` | 左下16pxの灰 | 出典・確認中の但し書き |

スタイル（`style="…"`）を本文に直接書かない。部品が足りなければ `theme/custom.scss` に足し、この表に加える（どのデッキも同じ見た目にするため）。
